## 네트워크관리사 2급 필기 모의고사

`network_admin_level2.html`을 내려받아 브라우저로 열면 됩니다(인터넷 연결 없이 동작, 글꼴만 온라인일 때 적용).

- 기출 15회차(2023.02 ~ 2026.08) 750문항을 중복 제거 없이 그대로 수록
- 랜덤 모의고사: 매 회차 과목별 출제 수(TCP/IP 17 · 네트워크 일반 10 · NOS 18 · 네트워크 운용기기 5)대로 50문항, 50분
- 회차별 기출, 과목별 바로 채점 풀이, 오답 다시 풀기
- 모든 문항에 정답 이유와 보기 ①~④ 풀이
- 학습 기록은 브라우저(localStorage)에만 저장
